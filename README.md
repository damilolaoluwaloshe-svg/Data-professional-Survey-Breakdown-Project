# Data Professional Salary & Career Survey Analytics
An end-to-end Business Intelligence project analyzing primary survey data from global data professionals. This project cleans, structures, and visualizes industry trends across compensation, job titles, programming languages, and workplace satisfaction.


## 📌 Business & Executive Summary
Understanding compensation benchmarks, technical skill demand, and workplace satisfaction is critical for data professionals and hiring teams alike. This project transforms raw survey feedback into an interactive Power BI dashboard to evaluate:
* How compensation correlates with experience, job roles, and geographic regions.
* Which technical skills (SQL, Python, R, Power BI) are most prevalent among top-earning cohorts.
* Overall workplace satisfaction and work-life balance trends across industry sectors.



## 🛠️ Data Architecture & Tech Stack
* **Business Intelligence & Visualization:** Microsoft Power BI (Data Modeling, Custom DAX Measures, Dynamic Filtering)
* **Data Processing & Transformation:** Microsoft Excel / Power Query (Data Cleansing, Null Handling, Normalization)
* **Schema Layout:** Relational Data Model (`DataModel`) with custom layout formatting (`Report/Layout`)


## 📊 Key Insights & Analytical Highlights
1. **Compensation Distribution:** Evaluated salary metrics across primary titles (*Data Analysts, Data Engineers, Data Scientists, BI Developers*) to establish clear salary benchmarks.
2. **Tech Stack Dominance:** Analyzed primary tool preferences, revealing high adoption rates for **SQL** and **Power BI** in business analytics roles.
3. **Satisfaction Index:** Modeled tenant satisfaction metrics against work-life balance and remote work flexibility.
